YOUR OWN LIST OF PLACES IN NIGERIA (schools, hospitals, offices)

The PPA page searches this list first, so it finds places fast and needs no outside service.
It starts EMPTY. You fill it by loading free data files, one at a time.

WHERE TO GET FILES (always read each page's licence and terms before you use a file)
  * EASIEST (one page, plain download links): the Humanitarian Data Exchange, https://data.humdata.org
        - "Nigeria - Education Facilities" (GRID3, Creative Commons Attribution). Files listed: two shapefiles and
          NGA_Education_Facilities.xlsx. Download the .xlsx one (Excel). Keep a credit to GRID3 somewhere in your app.
        - "Nigeria - Health Facilities": look for a CSV, XLSX or GeoJSON file on its page.
        Load an Excel file the same way as a CSV:  python import_places.py NGA_Education_Facilities.xlsx --source "GRID3 schools" --kind school
        (first time only:  pip install openpyxl)
        Shapefile .zip files work too (first time only:  pip install pyshp).
        NOTE: the .xlsx on that page has names but NO coordinates; use a shapefile .zip from the same page instead.
  * Hospitals and clinics:  GRID3 Nigeria health facilities.
        https://grid3.org/geospatial-data-nigeria   (follow the Health facilities link to the GRID3 Data Hub)
        Choose the CSV or GeoJSON download.
  * Schools: some states have public school lists on https://open.africa (search "<state> public schools").
        These are older and cover only some states.
  * Anything else in OpenStreetMap: use https://overpass-turbo.eu , search for a state's schools or hospitals,
        then Export > GeoJSON (or Raw OSM data / JSON). Do one state at a time; whole-country exports are too big.
  * Your own lists: a spreadsheet saved as CSV with these column names (any of the usual spellings work):
        name, latitude, longitude, state, lga, ward (or town), address, type

LOADING A FILE (in the folder that holds app.py and nysc_companion.db)
    python import_places.py hospitals.csv --source "GRID3 health"
    python import_places.py benue_schools.geojson --source "Benue schools" --kind school --state Benue

    --source   a label for this file (so you can reload it later)
    --kind     school, health or other. Leave it out and it is guessed from each place's name and type.
    --state    only for lists with no state column (one-state files)
    --replace  deletes the places from an earlier load with the same --source, then loads the file again

It prints how many places were added. Places with no name, or with coordinates outside Nigeria, are skipped.
Loading the same file twice does not make duplicates. No restart is needed: new places show up straight away.

WHAT CORPS MEMBERS SEE
  * Searching "Government Secondary School, Gboko, Benue" looks in the shared list (PPAs other corps members pinned),
    then in this list, and only then asks the free map services.
  * "Browse schools and hospitals in an LGA" appears on the PPA page once this list has data.

THE ADMIN CAN FIX THINGS
  Add one place:    POST /api/places     (admin login needed; body: name, lat, lon, state, lga, town, address, kind)
  Remove one place: DELETE /api/places/{id}
  (A screen for this in the admin page can be added later.)
